# L'alphabet Devanāgarī (देवनागरी)

Ordre phonétique traditionnel de la grammaire sanskrite (Pāṇini).

## 1. Voyelles (स्वर, Svara)

| IAST | Devanāgarī | Prononciation indicative |
| :--- | :--- | :--- |
| **a** | अ | 'a' bref, intermédiaire entre notre 'a' et notre 'e' muet |
| **ā** | आ | 'a' long, similaire à 'â' |
| **i** | इ | 'i' bref |
| **ī** | ई | 'i' long |
| **u** | उ | 'ou' bref |
| **ū** | ऊ | 'ou' long |
| **ṛ** | ऋ | voyelle liquide, prononcée 'ri' ou 'ru' (comme chambre) |
| **ṝ** | ॠ | 'ṛ' long |
| **ḷ** | ऌ | liquide 'li' bref |
| **e** | ए | diphtongue longue, comme 'é' fermé |
| **ai** | ऐ | comme 'aïe' |
| **o** | ओ | comme 'o' long fermé |
| **au** | औ | comme 'ao' |

## 2. Consonnes (व्यञ्जन, Vyañjana)

### Gutturales (कण्ठ्य, Kaṇṭhya)
* **ka (क)** — sourde non aspirée (calme)
* **kha (ख)** — sourde aspirée (k-ha)
* **ga (ग)** — sonore non aspirée (gare)
* **gha (घ)** — sonore aspirée (g-ha)
* **ṅa (ङ)** — nasale gutturale (comme agneau / sing)

### Palatales (तालव्य, Tālavya)
* **ca (च)** — tcha (comme tchèque)
* **cha (छ)** — tch-ha
* **ja (ज)** — dja (comme djinn)
* **jha (झ)** — dj-ha
* **ña (ञ)** — gnya (comme vigne, cognac)

### Cérébrales / Rétroflexes (मूर्धन्य, Mūrdhanya)
* **ṭa (ट)** — t rétroflexe (langue retournée vers le palais)
* **ṭha (ठ)** — ṭ-ha
* **ḍa (ड)** — d rétroflexe
* **ḍha (ढ)** — ḍ-ha
* **ṇa (ण)** — n rétroflexe

### Dentales (दन्त्य, Dantya)
* **ta (त)** — t dental pur
* **tha (थ)** — t-ha
* **da (द)** — d dental
* **dha (ध)** — d-ha
* **na (न)** — n dental

### Labiales (ओष्ठ्य, Oṣṭhya)
* **pa (प)** — p
* **pha (फ)** — p-ha (et non 'f')
* **ba (ब)** — b
* **bha (भ)** — b-ha
* **ma (म)** — m

### Semi-voyelles (अन्तस्थ, Antastha)
* **ya (य)** — y (yeux)
* **ra (र)** — r roulé dental
* **la (ल)** — l
* **va (व)** — w / v doux

### Sibilantes & Aspirée (ऊष्मन्, Ūṣman)
* **śa (श)** — ch chuintant palatal (shall en anglais)
* **ṣa (ष)** — ch rétroflexe cérébral
* **sa (स)** — s sourd dental (sac)
* **ha (ह)** — h aspiré sonore

## 3. Alternances vocaliques (Guṇa & Vṛddhi)

| Base (Simple) | Guṇa | Vṛddhi |
| :--- | :--- | :--- |
| **a** | a | ā |
| **i, ī** | e | ai |
| **u, ū** | o | au |
| **ṛ, ṝ** | ar | ār |
| **ḷ** | al | āl |
